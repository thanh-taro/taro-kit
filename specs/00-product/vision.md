# TaroKit — Vision

**TaroKit is Taro's personal home on the web.** It is a fast, keyboard-first portal that launches every tool Taro builds, and a portfolio that shows who builds them.

## Problem
- Everyday utilities are scattered across ad-heavy, cluttered sites. Pasting data into unknown sites feels unsafe.
- Nothing remembers which tools you use. There are too many tabs.
- Taro builds each tool as a separate project. Without a hub those tools can't be found, launched the same way, or presented as one body of work.

## Who it is for
- PER-01 Owner, the primary user and daily launcher.
- PER-02 Visitor, the secondary audience: peers, recruiters, friends.

## Differentiators
1. **A portal, not a monolith.** Each tool is independent and is registered once in the catalog. A tool opens either embedded in the portal or in its own tab (PRN-01).
2. **Keyboard-first and fast.** One keystroke to search, plus favorites, recents and stable addresses for every tool (PRN-02).
3. **Private by default.** There are no accounts, analytics, ads or tracking. Personal state stays on the device (PRN-03).
4. **Personal identity.** The portfolio and the tools share one home (PRN-04).

## Non-goals
- Building individual tools in this product. Each tool is its own project.
- Accounts, sync, a server-side backend, analytics, ads, monetization, a blog, a third-party plugin marketplace.
- A runtime contract or shared design system between the portal and its tools.
- Languages beyond English and Vietnamese (F-019, D-060).
- Backing up a tool's own data. Each tool owns its data.

## Success
The first release succeeds when the Owner actually uses TaroKit as their daily launcher. The measurable bar is set in the delivery roadmap.
